# SDK 2.2.0 Bit2Me qualification

The 2026-09-19 version-5 consistency run records native `spot:A1X/USDC` ticker
bid/ask `0.0` against a stable one-sided book: bid absent, ask `0.0005999`.
All three timely, exact-ID brackets retain those observations as
`limitation/native_ticker_quotes`. The quote comparison did not pass; its known
upstream limitation satisfies the policy in
[ADR 0022](../../dev-docs/adr/0022-bit2me-one-sided-ticker-limitation.md).
All Bit2Me read-suite cases passed.

Earlier version-4 reports blocked this shape because ADR 0014 required two-sided
books. The current report was generated by a fresh live run after the policy
amendment. Historical report contents were not relabeled.

The SDK preserves native ticker values. Other venues, malformed data, changing
book sides, wholly empty books, incomplete brackets and request errors remain
outside this exception. All other read-suite and consistency gates still apply.
