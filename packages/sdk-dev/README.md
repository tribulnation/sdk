# SDK developer tools

Internal development and release-qualification tooling for the Tribulnation SDK.
This package is not part of the public SDK interface.

1. [Contributor guide](https://github.com/tribulnation/sdk/blob/main/CONTRIBUTING.md)
   covers installation, development commands and repository conventions.
2. [Local SDK checks](https://github.com/tribulnation/sdk/blob/main/dev-docs/local-checks.md)
   documents read-only live tests, fingerprinted results and offline release checks.
3. [Architecture decisions](https://github.com/tribulnation/sdk/tree/main/dev-docs/adr)
   records the contracts and qualification policy.
